Docker Setup for Running Flutter App

Prerequisites

  • Your PC and Phone must be on the same network.

Phone Setup

  1. Connect your phone to your PC through USB Cable.
  2. Enable Developer Options on your phone.
  3. Go down to Debugging Section:
    • Enable USB Debugging.
    • Enable Wireless Debugging.

Docker Setup

  1. Download and Install Docker Desktop from the official website.
  2. Run the Docker Daemon.

Laptop/PC Setup

  1. Download Git from the official website.
  2. Open the Windows terminal or any folder where you want to clone the Flutter project.
  3. Clone the Flutter project:
    • Run: git clone https://github.com/ekaantik/ecard-flutter-app.git
    • Change directory to the project root: cd ecard-flutter-app

Build Image

  • Run: docker build -t parichay-card .
  • Be patient as it may take up to 20 minutes.

Run the Container

Run the Docker container with the appropriate phone IP address:

  • Run: docker run -e PHONE_IP_ADDRESS=<ip_address_of_phone> -it parichay-card
  • Replace <ip_address_of_phone> with the IP address of your phone.
  • While running, There will a popup message asking to allow USB Debugging. Click on the Always allow from this Computer option toogle and re-run the above command."
  • Wait for the Gradle Build, It may take 5-10 mins.
  • The app will start running on your phone.

Note: When you receive the message "Device connected successfully!" on the terminal, you can unplug the USB cable from the phone.
